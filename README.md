# 日记本

SillyTavern 扩展。角色会为你们的故事写日记，你可以收藏喜欢的楼层。

## 装

把整个 `st-diary` 文件夹放进：

```
SillyTavern/public/scripts/extensions/third-party/st-diary/
```

刷新页面。魔棒菜单里会出现「日记本」。

## 用之前先配一次

打开日记本 → 封面左下角齿轮 → 设置。

**两个模型都要配。** 看时间的挑便宜的，写日记的挑写得好的。

- **独立 API**：填地址（末尾带 `/v1`）、密钥，点「拉取」选模型，点「测试连接」确认通了。
- **酒馆当前**：借用酒馆的连接，走它的后端转发。不会切换你正在用的配置。

填完往下翻，勾上要给它看的世界书。默认只勾角色卡绑定的那本。

## 关于独立 API 的 CORS

独立模式是浏览器直连。Gemini、OpenRouter、多数中转站没问题，**OpenAI 官方端点会被浏览器拦掉**。

「测试连接」报「不允许浏览器直连」就是撞上了，把连接方式换成「酒馆当前」。

## 它什么时候动笔

两个条件，可以都开：

- **新一天** — 故事翻到新的一天时，为上一天写。
- **每 N 层楼** — 攒够 N 层就写一篇。

**「等下一条消息再动笔」建议一直开着。** 开着的时候，角色回完不会立刻处理，要等你发出下一条消息才算上一条定稿。所以你重 roll、编辑、删楼都不会触发它写。

## 删楼层会不会乱

不会。所有定位用的是消息自身的唯一标识，不是楼层号。你删前面的楼、插楼、换分支，已写好的日记都不会认错。

源楼层被删掉的日记不会跟着消失，只会标上「源楼层已删」，删不删你自己决定。收藏也一样，收藏时的原文快照一直留着。

## 数据放哪

- 日记、收藏、日期标记 → 存在**这个对话**里，跟着聊天文件走，切角色就换一本。
- 设置、API 密钥 → 全局。

密钥以明文存在酒馆的 `settings.json` 里。公用机器上注意。

## 提示词

「怎么写」那一栏是日记的提示词，随便改。可用变量：

`{{char}}` `{{user}}` `{{date}}` `{{content}}` `{{world}}` `{{memory}}`

下面折叠的「看时间用的提示词」不用管，除非你的时间格式很特殊。它必须只回 JSON。

## 让时间检测几乎不花钱

如果你的角色卡把时间放在固定标签里（状态栏、Slate 之类），去设置 →「只看正文」→「**时间在哪**」填一条正则：

```
<Ti>([^<]*)</Ti>
```

填了之后，插件只从这一小段读日期，不会把整段正文喂给模型。而且下面这些写法它本地就能解析，**一次请求都不发**：

- `2007年3月15日·星期四·19:32`
- `2007-03-15` / `2007/3/15` / `2007.3.15`
- `3月15日`（缺年份就补故事的年份）
- `March 15, 2007` / `15 Mar 2007`

只有正则抠不到、或者抠到了但认不出格式，才会去问模型，而且只问抠出来那一小段。

不知道正则怎么写？点「让它读一条，猜猜看」，它会读一条角色回复，把建议填进框里，你确认一下就行。

## 预设在哪

「独立 API」模式下**没有预设**，只有地址、密钥、模型、温度，提示词用插件自己的。

预设只在「酒馆当前」模式里 —— 把连接方式切过去，才会出现「连接配置」下拉，里面是你在 SillyTavern 的 Connection Manager 建的那些配置。切回独立模式它就隐藏了。
