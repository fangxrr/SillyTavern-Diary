# 日记本

SillyTavern 扩展。角色会为你们的故事写日记，写在一台打字机旁边的便签上。

## 装

整个文件夹放进 `SillyTavern/public/scripts/extensions/third-party/`，刷新页面。
魔棒菜单里会出现「日记本」。

## 怎么用

打开是一台打字机。滚筒上那张纸显示当前状态，下面四个键：

- **便签** — 写过的日记，一张一张钉在墙上。点开摊成整页。
- **日历** — 哪几天写过。写过的日子是一张浅色纸片。
- **设置** — 全部配置都在这里，分 A 到 H 八节。
- **补写** — 自己指定楼层范围写一张。红色的键，因为它会真的花钱。

## 用之前先配一次

设置 → B 和 C 两节，两个模型都要填。看时间的挑便宜的，写日记的挑写得好的。

- **独立 API**：填地址（末尾带 `/v1`）、密钥，点「拉取」选模型，点「测试连接」。
- **酒馆当前**：借用酒馆的连接，走它的后端转发，不会切换你正在用的配置。

独立模式是浏览器直连。Gemini、OpenRouter、多数中转站没问题，**OpenAI 官方端点会被浏览器拦掉**——测试连接会告诉你，撞上了就换成「酒馆当前」。

然后往下到 D 节，勾上要给它看的世界书。**记得勾「只取常驻条目」**，不然整本塞进去会很贵。

## 让时间检测几乎不花钱

角色卡把时间放在固定标签里的话（状态栏、Slate 之类），去 E 节的「时间在哪」填一条正则：

```
<Ti>([^<]*)</Ti>
```

填了之后只从这一小段读日期。而且下面这些写法本地就能解析，**一次请求都不发**：

- `2007年3月15日·星期四·19:32`
- `2007-03-15` / `2007/3/15` / `2007.3.15`
- `3月15日`（缺年份补故事的年份）
- `March 15, 2007` / `15 Mar 2007`
- `2023年5月6日~5月10日`（跨天范围取最后一天）

不会写正则就点「让它读一条，猜猜看」。

**E 节那两条正则只对当前这张卡生效**，换角色互不影响。

## 它什么时候动笔

A 节两个条件，可以都开：

- **新一天** — 故事翻到新的一天，为上一天写。
- **每 N 层楼** — 攒够就写一张。

**「等下一条消息再动笔」建议一直开着。** 角色回完不会立刻处理，要等你发出下一条才算定稿。所以重 roll、编辑、删楼都不会触发它。

同一天后来又有新楼层的话，它会从这天的起点重读一遍整天重写，保证那张便签覆盖当天全部。

## 删楼层会不会乱

不会。定位用的是消息自身的唯一标识，不是楼层号。删前面的楼、插楼、换分支，写好的都不会认错。

源楼层被删的日记不会消失，摊开会标「源楼层已删」，撕不撕你自己决定。

## 写得不对怎么查

设置 G 节有运行日志，记着每次生成读了哪几楼、日期怎么判的、注入了多少世界书、实际喂进去什么。有「复制全部」按钮。浏览器控制台也会同步打 `[日记本]`。

两条硬约束会自动挡掉离谱的日期：不早于起始日、不倒退。被改动的都记在日志里。

**日记写到一半断掉**是撞了 C 节的「上限」。会弹提示，把上限调大再点那张的「重写」。注意带 thinking 的模型，思考也算在上限里。

## 数据放哪

- 日记、日期标记 → 存在**这个对话**里，跟着聊天文件走，切角色就换一墙。
- 设置、API 密钥 → 全局。密钥以明文存在酒馆的 `settings.json`，公用机器上注意。

## 提示词

F 节可以改。可用变量：

`{{char}}` `{{user}}` `{{date}}` `{{content}}` `{{world}}` `{{memory}}`
